# Listing screenshots

Save screenshots manually from Chrome with authorC installed and enabled on [the Nature example article](https://www.nature.com/articles/nclimate1389).

| Filename | View |
| --- | --- |
| `01-nclimate1389-panel.png` | Expanded panel showing Author C and the ranked author list. |
| `02-nclimate1389-compact.png` | Minimized pill showing the leading author’s name and count. |

Use **1280 × 800 PNG** images for the listing. Replacing these files updates the images displayed in the repository README. Check that the article and panel are readable and that no private account details or API keys are visible.

See [Chrome’s screenshot requirements](https://developer.chrome.com/docs/webstore/images#screenshots).
